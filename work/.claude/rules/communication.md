# Communication rules

- Brief, concise, precise. Do not over-explain.
- Prefer tables, bullets and numbered lists over prose.
- Prefer `.md` over `.docx` or `.html` unless the user asks for another format.
- Never use the em dash character. Use `,` `;` `:` or a plain hyphen.
- Preserve the user's original phrasing and intent when processing their notes.
- When sharing a file: a short summary plus a path link, no long closing text.
- Before drafting a message to another person, read `<path to your voice profile>` if you have one.
- Any mention of a task, channel, thread, meeting or file must be written as `[title (id)](link)`, never a bare id.
